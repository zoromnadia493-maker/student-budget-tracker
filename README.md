# Student Budget Tracker

## Project Objective

The Student Budget Tracker is a simple web application designed to help students manage their monthly budget and track their expenses.

The application allows users to set a monthly budget, add expenses, view their total spending, and see how much money remains.

## Features

- Set a monthly budget
- Add an expense
- Select an expense category
- View total amount spent
- View remaining budget
- Delete an expense
- Validate expense information
- Prevent expenses from exceeding the remaining budget

## Technologies Used

- HTML
- CSS
- JavaScript

No external libraries or dependencies are required.
